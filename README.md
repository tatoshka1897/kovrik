# Коврик — окошко записи

Мини-приложение Telegram для записи на творческие посиделки «Коврика» (м. Семёновская).
Открывается из бота @kovrik_zapis_bot. Адрес: https://tatoshka1897.github.io/kovrik/ Данные — у бота (Cloudflare Worker, /api/meetings, /api/book, /api/slots, /api/request). Внизу блок «Ещё в «Коврике»» — своя компания, аренда, сотрудничество с выбором дня и часов прямо в окошке (виден при `?test` или включённом новом меню).
